Mod pour Everest

Chaque tentative, enregistrée pendant que tu joues.

Celeste Death Tracker est un mod pour Everest, le chargeur de mods de Celeste. Il envoie chaque tentative au site, qui te montre jusqu'où tu vas sur chaque face.

Installer le mod Voir le code sur GitHub

Pas encore publié

Ni sur GameBanana ni dans l'installeur d'Everest : pour l'instant, il se compile et s'installe à la main.

Ce que fait le mod

Il enregistre

Une tentative va de ton entrée dans une face à ta sortie. Le mod note :

  • la map, la face (A, B ou C) et l'emplacement de sauvegarde ;
  • les rooms traversées, dans l'ordre ;
  • chaque mort : la room, la position dans la room et le temps de la partie ;
  • la fin de la tentative : face terminée, chapitre recommencé, abandon, retour au menu, jeu fermé…

Il n'enregistre rien d'autre

  • ni fichiers, ni autres jeux, ni informations sur ton ordinateur ;
  • rien du tout tant que le jeu n'est pas associé à ton compte ;
  • rien non plus si tu désactives l'envoi dans le menu du mod.
Le détail des données

Il ne ralentit pas le jeu

Le mod n'attend jamais le serveur. Si le site ne répond pas, tu continues à jouer normalement.

Installer le mod

Quatre étapes, une seule fois. Il te faut :

  • Celeste avec Everest
  • le SDK .NET 8, pour compiler
  • Git, ou le dépôt en ZIP
  1. 1

    Récupère le code

    Clone le dépôt CelesteDeathTracker, ou télécharge-le en ZIP.

    git clone https://github.com/matthisRipoche/CelesteDeathTracker.git
cd CelesteDeathTracker
  2. 2

    Compile le mod

    Indique le dossier de Celeste, celui qui contient Celeste.dll.

    dotnet build CelesteDeathTracker -c Release -p:CELESTE_PATH="C:\chemin\vers\Celeste"
  3. 3

    Copie les deux fichiers dans Mods

    Ferme Celeste, crée le dossier Mods/CelesteDeathTracker/ dans le dossier du jeu, puis copie-y :

    • CelesteDeathTracker.dll, produit par la compilation dans CelesteDeathTracker/bin/Release/net8.0/ ;
    • everest.yaml, qui se trouve dans CelesteDeathTracker/.
  4. 4

    Lance Celeste

    Le mod apparaît dans Mod Options, sous le nom CelesteDeathTracker.

Associer le jeu à ton compte

Aucun mot de passe ni aucune clé à copier dans le jeu : un code suffit.

  1. 1

    Au premier lancement, le jeu affiche un code et ouvre la page d'association du site dans ton navigateur.

  2. 2

    Connecte-toi, puis saisis le code.

  3. 3

    C'est associé. Tes tentatives arrivent sur le site à partir de ce moment.

Pour associer le jeu à un autre compte : Associer ce jeu à un autre compte, dans le menu du mod.

Désinstaller

Supprime le dossier Mods/CelesteDeathTracker/. Les tentatives déjà envoyées restent sur ton compte.
